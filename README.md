# dvigprikatka — ESP32, LCD, энкодер, 4 реле

Контроллер прикатки/обкатки двух двигателей на ESP32.

## Что делает программа

Через энкодер с кнопкой на LCD выбираются:

1. Время вращения вправо: **1 / 2 / 3 минуты**.
2. Время вращения влево: **1 / 2 / 3 минуты**.
3. Общее количество циклов: **1...999**.
4. Пункт **START** запускает работу.

По умолчанию установлено:

- вправо — 1 минута;
- влево — 2 минуты;
- 10 циклов.

Один полный цикл считается так:

1. Оба двигателя вращаются вправо.
2. Все реле выключаются на 0,8 с.
3. Оба двигателя вращаются влево.
4. Все реле выключаются на 0,8 с.
5. Счётчик полного цикла увеличивается.
6. Начинается следующий цикл.

При нажатии кнопки энкодера во время работы установка немедленно останавливается и все реле выключаются.

## Реле

| Реле | GPIO ESP32 | Назначение |
|---|---:|---|
| Relay 1 | GPIO16 | Двигатель 1 — вправо |
| Relay 2 | GPIO17 | Двигатель 1 — влево |
| Relay 3 | GPIO18 | Двигатель 2 — вправо |
| Relay 4 | GPIO19 | Двигатель 2 — влево |

Программа никогда специально не включает одновременно реле RIGHT и LEFT одного двигателя.
Между сменой направления добавлена пауза 800 мс.

> Важно: силовое переключение двигателя должно быть собрано так, чтобы одновременное включение противоположных направлений физически не приводило к короткому замыканию. Для мощного двигателя рекомендуется дополнительная аппаратная блокировка контакторами/реле.

## Энкодер EC11 / KY-040

| Энкодер | ESP32 |
|---|---:|
| CLK / A | GPIO32 |
| DT / B | GPIO33 |
| SW | GPIO25 |
| GND | GND |

В коде используются внутренние `INPUT_PULLUP`, поэтому кнопка и контакты энкодера замыкаются на GND.

Если направление прокрутки получилось обратным — поменяйте местами A и B либо GPIO32/GPIO33.

## LCD 20x4 I2C

По умолчанию используется LCD 20x4 с PCF8574 и адресом `0x27`.

| LCD I2C | ESP32 |
|---|---:|
| SDA | GPIO21 |
| SCL | GPIO22 |
| GND | GND |
| VCC | согласно модулю дисплея |

Если Ваш LCD имеет адрес `0x3F`, измените в `src/main.cpp`:

```cpp
static constexpr uint8_t LCD_ADDRESS = 0x27;
```

на:

```cpp
static constexpr uint8_t LCD_ADDRESS = 0x3F;
```

## Логика меню

Главный экран:

```text
> Right: 1 min
  Left : 2 min
  Cycles: 10
  START
```

- вращение энкодера — перемещение по меню;
- нажатие — вход в настройку;
- вращение в режиме настройки — изменение значения;
- повторное нажатие — сохранить и вернуться;
- на `START` — запуск.

Во время работы, например:

```text
Cycle 3/10 RIGHT
M1:2 M2:2
Remain 00:41
Press = STOP
```

`M1` и `M2` показывают количество полностью завершённых циклов каждого двигателя.

## Активный уровень реле

По умолчанию предполагается обычный 4-канальный модуль реле с входами **active LOW**.

В `src/main.cpp`:

```cpp
static constexpr bool RELAY_ACTIVE_LOW = true;
```

Если Ваш модуль включается высоким уровнем, поменяйте на:

```cpp
static constexpr bool RELAY_ACTIVE_LOW = false;
```

## PlatformIO

Открыть папку проекта в VS Code + PlatformIO и выполнить:

```bash
pio run
pio run -t upload
pio device monitor
```

Среда в `platformio.ini`:

```ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
monitor_speed = 115200
```

Если используется другая конкретная плата ESP32, замените параметр `board`.

## Файлы

- `platformio.ini` — настройки PlatformIO;
- `src/main.cpp` — вся прошивка ESP32.
